# chatbot (ผู้สอนเปิด นักเรียนใช้ผ่านเบราว์เซอร์)

หน้าแชต Streamlit สำหรับดูสถานะและสั่งงานโคมไฟ (เรียก gateway ที่ `http://127.0.0.1:8000`)

```powershell
streamlit run chatbot/app.py
```

รันจาก**โฟลเดอร์หลักของ repo** (ใช้ `.streamlit/config.toml` ที่ตั้งพอร์ต 8501 และให้เครื่องอื่นเปิดได้) ต้องติดตั้ง `pip install streamlit` ก่อน

เปิด `http://<IP ของ gateway>:8501` ถ้าอยู่คนละเครื่องกับ gateway ให้ตั้ง `AIOT_GATEWAY_URL`

พิมพ์ `เปิดไฟ`, `ปิดไฟ`, `อัตโนมัติ` หรือถามสถานะ ข้อความถูกแปลเป็นคำสั่งที่ gateway (ด้วยกฎ หรือด้วย Gemma เมื่อเปิด) และใต้คำตอบแสดงคำสั่ง JSON ที่ระบบเข้าใจ ปุ่มด้านบนเรียก `POST /v1/control` โดยตรง

sidebar มีช่อง **system prompt ของคุณ** ที่ถูกต่อก่อนข้อความจริงตอนส่งให้ AI และมีแผง "ดูข้อความที่ประกอบส่งให้ AI" ใต้คำตอบ เพื่อให้นักเรียนเข้าใจการประกอบ prompt (ตัวแปลงแบบกฎไม่อ่าน prompt)
